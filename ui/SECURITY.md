# Security Policy

## Supported Versions

Security fixes are handled for the latest released package versions.

## Reporting a Vulnerability

Do not report exploitable vulnerabilities in a public issue.

Use GitHub private vulnerability reporting for this repository when available. If it is not enabled, contact the maintainers privately through the Extrittio organization contact channel.

Please include:

- affected package and version
- impact and expected exploit conditions
- reproduction steps or a minimal proof of concept
- any known mitigations

Maintainers will confirm receipt, assess severity, and coordinate a fix before public disclosure.
