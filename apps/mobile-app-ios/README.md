# Extrittio iOS

Native SwiftUI companion app for the Extrittio IoT Hub. It provides permission-aware dashboards, a device map, device management, telemetry, commands, alerts, rules, firmware management, administration, and a disposable offline cache for self-hosted deployments.

## Requirements

- Xcode 26.x with the iOS 26 SDK
- XcodeGen, SwiftLint, and SwiftFormat versions listed in `Tools/versions.env`

The app uses Apple frameworks only; it has no third-party runtime dependencies.

## Quick Start

From the Extrittio repository root:

```bash
cd apps/mobile-app-ios
make bootstrap
make build
make test
```

`make bootstrap` validates the expected local tool versions and regenerates `Extrittio.xcodeproj` from `project.yml`. The generated project is intentionally ignored by git.

By default, tests use the latest installed runtime for an `iPhone 17 Pro`. Override either value when needed:

```bash
SIMULATOR_NAME="iPhone 16 Pro" SIMULATOR_OS="26.5" make test
```

## Common Commands

```bash
make generate       # Regenerate the Xcode project
make build          # Debug simulator build
make staging        # Staging simulator build
make release        # Release simulator build
make test           # Unit tests
make lint           # SwiftLint
make format         # Apply SwiftFormat
make format-check   # SwiftFormat in lint mode
make module-check   # Validate module boundary rules
```

## Server Configuration

Configuration values live in `Config/*.xcconfig`.

- `Debug`: permits HTTP for local development and defaults to port `8080`
- `Staging`: requires HTTPS and uses the default HTTPS port
- `Release`: requires HTTPS and uses the default HTTPS port

Users provide the backend host or full URL in the app. Changing servers signs out the current session and clears cached account data. Authentication stores the JWT and current-user record in the device Keychain; passwords are never retained.

## Architecture

The project uses Swift 6 strict concurrency, SwiftUI, `@Observable` view models, repository/use-case boundaries, `URLSession`, and a SwiftData-backed cache.

- `Domain`: entities, repository protocols, and use cases
- `Data`: REST transport, endpoint construction, Keychain, cache, and repository implementations
- `Presentation`: views, view models, shared UI, and the design system
- `DI`: composition root and dependency wiring

The Xcode project is generated by XcodeGen. Run `make generate` after changing `project.yml` or adding or removing Swift files.
