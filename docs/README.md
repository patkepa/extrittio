## Sources of truth

When documentation and implementation disagree, use these in order and fix the
documentation in the same change:

1. command help generated by the current binaries;
2. `api/openapi.json` for the HTTP contract;
3. manifests, configuration parsing, Compose files, and packaging scripts;
4. this documentation.

Use `cargo xtask --help`, `cargo run -p extrittio -- --help`, and
`npm run` to discover the current command surfaces. Avoid copying generated API
schemas or long configuration lists into prose when a maintained source can be
linked directly.
